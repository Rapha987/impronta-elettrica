# Impronta Elettrica

Sito per **Impronta Elettrica di Troia Cesario** (Andria): il cliente carica le foto del lavoro e la richiesta arriva come preventivo, anche su WhatsApp.

## Come si usa

1. Apri **Invia una foto del lavoro**
2. Carica 1–5 foto (fotocamera o galleria)
3. Tipo di lavoro, descrizione, nome, telefono, zona
4. Invia: sul telefono si apre WhatsApp con **testo + foto** da mandare a Cesario
5. La pratica resta anche nel **Pannello tecnico**

Pannello tecnico: codice `andria28`

## Sviluppo

```bash
npm install
npm run dev
```
